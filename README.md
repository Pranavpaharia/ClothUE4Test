# ClothUE4Test

A testbed for **cloth simulation in Unreal Engine 4** (built for UE **4.24**).

Small experiment project used to validate cloth physics settings: mesh cloth assets, painter weight setup, and runtime behavior (wind, collision, constraints). Useful as a starting point for character cloth/garment work.

## Requirements
- Unreal Engine **4.24**

## How to run
1. Clone the repository.
2. Open the `.uproject` with UE 4.24.
3. Press **Play** to see the cloth react to the scene (wind/dragging).

## Notes
- Large commit history only, no releases — this is an experiment snapshot.
- If it fails to load, confirm the UE version (4.24) matches your installed engine.
